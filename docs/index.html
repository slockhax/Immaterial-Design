Immaterial Design System

A small, framework-free UI kit built on Material Design principles. One stylesheet, one optional behaviour script, automatic light & dark mode, and a colour system that rebrands from a single seed colour.

Overview
What's included
Everything you need to build polished data-dense interfaces — dashboards, admin panels, tooling UIs — without adding a framework dependency.
style
One stylesheet
immaterial.css — all component styles, no hardcoded colours, no build step.
code
~5 KB of JS
immaterial.js adds dialogs, toasts, sliders, tabs, and menus. Everything else is pure CSS.
palette
Semantic colour system
Material Design role tokens computed from a few seed colours. Rebrand by changing one hex.
dark_mode
Light & dark built in
Every token carries both values via light-dark(). OS auto-detection or manual override.
table_chart
30+ components
Buttons, forms, tables, cards, charts, dialogs, toasts, nav — all coordinated.
block
No dependencies
Vanilla HTML, CSS, and JS. Works in any stack. Evergreen browsers, no polyfills.

Setup
Installation
Three files, no build step. Add the fonts, drop in the stylesheets, and include the script before </body>.
1
Self-host the fonts
The system uses Roboto Flex (UI text), Material Symbols Rounded (icons), and optionally Roboto Mono. Serve the .woff2 files from your own assets and declare them under these exact family names. The fonts folder in this repo includes the files.
@font-face {
  font-family: 'Roboto Flex';
  src: url('/fonts/RobotoFlex.woff2') format('woff2');
  font-weight: 100 1000;
  font-display: swap;
}
@font-face {
  font-family: 'Material Symbols Rounded';
  src: url('/fonts/MaterialSymbolsRounded.woff2') format('woff2');
  font-weight: 100 700;
  font-display: swap;
}
@font-face {
  font-family: 'Roboto Mono';
  src: url('/fonts/RobotoMono.woff2') format('woff2');
  font-weight: 100 700;
  font-display: swap;
}
2
Load the stylesheets
theme.css must come before immaterial.css — every component colour references a token defined in the theme file.
<link rel="stylesheet" href="theme.css">    <!-- tokens first -->
<link rel="stylesheet" href="immaterial.css">
3
Add the behaviour script
Add immaterial.js before </body>. It auto-initialises sliders, tabs, menus, and dialogs. If you inject markup dynamically, call Immaterial.init() to wire the new elements.
<script src="immaterial.js"></script>
4
Set the colour scheme on <html>
For OS-based auto mode, add nothing. To force a theme on load, set data-theme. Immaterial.setTheme() updates this attribute at runtime and persists the choice in localStorage.
<html data-theme="light">   <!-- force light -->
<html data-theme="dark">    <!-- force dark -->
<html>                       <!-- follows the OS (default) -->
Theming
Rebranding in one step
All colour lives in theme.css. Change --seed-primary and the full token set — containers, on-colours, surfaces, hover states, chart bars, focus rings, shadows — is recalculated automatically for both light and dark modes.
tips_and_updates
Rebrand checklist Change --seed-primary to your brand colour. Override --seed-secondary and --seed-tertiary to break from the auto-derived hues. Spot-check contrast on extreme seeds (neon, very light) and pin any offender with a literal override like :root { --on-primary-container: #1A1400; }. 
/* theme.css — the only file a designer edits */
:root {
  --seed-primary:   #2563EB;   /* change to your brand colour */
  --seed-secondary: #6D7C8A;   /* optional — defaults to a muted sibling */
  --seed-tertiary:  #7C5EBD;   /* optional — defaults to +60° hue shift */
  --seed-error:     #B3261E;
  --seed-success:   #0E7A43;
  --seed-warning:   #9A6A00;
}
For the full token reference and light/dark mode instructions, see Color & Theming →
JavaScript
The Immaterial API
The script exposes a single global object. Most behaviours (menus, table group toggles) wire themselves automatically — you only call the API for toasts, dialogs, and theme changes.
Immaterial.toast(msg, opts) Show a snackbar. Optional actionLabel, onAction, duration. Returns dismiss().
Immaterial.openDialog(id) Open a dialog by its element ID.
Immaterial.closeDialog(id) Close a dialog by its element ID.
Immaterial.setTheme(mode) Set 'light', 'dark', or 'auto'. Persists to localStorage.
Immaterial.init(root?) Re-wire sliders and tabs inside root (defaults to document) after injecting dynamic markup.
Compatibility

Targets evergreen Chrome, Edge, Firefox, and Safari (2024+). No build step, no polyfills, no transpilation.
