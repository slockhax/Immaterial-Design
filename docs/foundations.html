Foundations

The colour system and typography roles that every component is built on. Start here to understand how to rebrand the system and how to apply text consistently.

Color
Seed-based token system
All colour lives in theme.css. The entire palette — containers, on-colours, surfaces, states — is computed from a small set of seed colours using oklch(from …) relative colour syntax. Every token carries both a light and a dark value via light-dark(), so there is no separate dark-mode block to maintain.
palette
When to customise To rebrand: edit the --seed-* values in theme.css — that's the only file a designer touches. For extreme seeds (very light, neon) spot-check contrast and override any derived token with a literal value using the escape hatch.

Light & dark mode
Toggle the switch above to see the token set adapt. Three modes are supported:
data-theme="light"Force light mode regardless of OS preference
data-theme="dark"Force dark mode regardless of OS preference
(no attribute)Follow the OS setting — the default

At runtime: Immaterial.setTheme('light' | 'dark' | 'auto') — persists in localStorage.

Override any token
Every computed token can be overridden with a literal value in your own stylesheet. This is useful for extreme seeds that produce low-contrast derived colours:
/* In your app's stylesheet, after theme.css */
:root {
  --on-primary-container: #1A1400;   /* override a single derived token */
  --seed-secondary:       #5B7FA6;   /* or lock a seed to break auto-derivation */
}
Typography
Text roles
Five type roles for free-standing text. Components carry their own type, so these classes are for section headers, card labels, KPI values, and body copy. Apply them to any element — heading tags carry no intrinsic styling.
tips_and_updates
Choosing a role Use .text-value for single numbers that need to read at a glance (KPIs, stat cards). Use .text-title for section and card headings. Default to .text-body for prose. Use .text-label for secondary context next to a primary value. Reserve .text-overline for group headers above a list or table — it demands a lot of vertical space for what it communicates, so use it sparingly.
.text-value 1,284 28px / 700 — KPIs, indicators
.text-title Maintenance queue 16px / 650 — section headers
.text-body All systems reported nominal during the last inspection window. 14px / 400 — default copy
.text-label Open work orders 13px / 500 muted — card labels
.text-overline Facilities — Zone 4 11px / 700 caps — group headers
.text-overline--rule Facilities — Zone 4 adds a rule to container edge
