The label’s background = the surface behind the field (var(--surface) inside a card). Put a field directly on the page and set .field__label { background: var(--surface-dim); } so the border still “breaks” cleanly around the text. The small field (field--sm, 32px) is for toolbars and dense contexts — use a placeholder or adjacent label, not the notched label.

Data table

Native <table> — fills its container, columns size to content (or pin widths via <colgroup>). Cells use font-variant-numeric: tabular-nums, so numeric columns align digit-for-digit. Toggle density, column visibility, select rows, sort. Column filters (see filter mockup for the live demo + wiring) and group rows are optional add-ons. See README for the full recipe.
