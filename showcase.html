Split button

Primary action + a menu of secondary actions. JS wires the menu via data-menu-toggle.

Segmented buttons

Pure CSS — radio inputs. Selected option shows a check. No JS needed.

Text fields

The notched label sits on the border; its background matches the surface behind the field. Because these fields sit inside a card (--surface), the label reads seamlessly — see the note below.

The label’s background = the surface behind the field (var(--surface) inside a card). Put a field directly on the page and set .field__label { background: var(--bg); } so the border still “breaks” cleanly around the text.
